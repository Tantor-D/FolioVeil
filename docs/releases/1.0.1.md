# FolioVeil 1.0.1 · 2026-10-17

修复 Chrome 商店上传 ZIP 时提示“找到多个 manifest.json”的问题。内部主题资源清单改名为 `theme-manifest.json`，扩展根目录仍使用标准 `manifest.json`；读取路径同步更新。

构建会递归检查输出目录，只允许根目录存在一份 `manifest.json`。本次不改变阅读界面、功能和主题资源。

类型检查、501 项测试和构建通过；最终 ZIP 已验证仅含根目录扩展清单，主题资源完整性检查通过。本次尚未在 Chrome 商店重新上传，也不代表商店审核通过。

1.0.0 可继续用于本地解压加载，但其原 ZIP 不适合商店上传。开发者提交商店时请使用 1.0.1 或后续已修复的包。GitHub 现有 1.0.0 标签和附件保持不变，已发布 ZIP 版本以 Releases 页面为准。
